# Bike Sharing Dashboard 🚲

## Setup Environment
Pastikan Anda memiliki Python yang sudah terinstal. 
Buka terminal/command prompt, navigasikan ke folder proyek ini, lalu jalankan perintah berikut untuk menginstal semua library yang dibutuhkan:

pip install -r requirements.txt

## Run Streamlit App
Setelah instalasi selesai, jalankan dashboard dengan perintah berikut:

streamlit run dashboard/dashboard.py
